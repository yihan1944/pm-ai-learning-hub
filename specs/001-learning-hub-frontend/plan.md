# Implementation Plan: AI Learning Hub Frontend

**Branch**: `master` | **Date**: 2026-05-21 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-learning-hub-frontend/spec.md`

## Summary

Build a Vue 3 + Vite frontend for the PM AI System learning project. The site presents论文笔记、学习路线、术语表、Agent 资源和面试题 in a browsable, searchable, mobile-responsive SPA. Content pre-processed from existing markdown files via a Python build script into JSON, consumed by Vue components. Static output deployable to any host. No backend, no database.

## Technical Context

**Language/Version**: Python 3.11 (build script), Vue 3 + TypeScript, Vite 6

**Primary Dependencies**: Vue 3, Vue Router, Python-Markdown, marked (client-side paper rendering)

**Storage**: localStorage (user progress), JSON files (content data, imported by Vite)

**Testing**: Manual browser testing (Chrome, Firefox, Safari, Edge)

**Target Platform**: Modern browsers, responsive 320px-2560px+

**Project Type**: Vue SPA (static output)

**Performance Goals**: Homepage loads in < 3 seconds

**Constraints**: No server runtime, no database, no external API calls

**Scale/Scope**: ~50 content items, 5 categories, 10 paper notes

**Structure Decision**: Vue 3 SPA with Vite. Python build script generates JSON data files under `src/data/`. Vue components import JSON directly (Vite native support). Vue Router handles client-side navigation. Build output in `dist/` is a fully static site.

## Implementation Tasks (Preview)

### Build Script (`build.py`)
1. Parse markdown from papers/, knowledge/, agents/, ai-products/, exam/
2. Extract metadata and convert content to HTML
3. Output JSON files to src/data/

### Vue Components
1. App.vue + NavBar — shell with navigation
2. HomeView + CategoryCard — homepage
3. PapersView + PaperDetailView — paper browsing
4. KnowledgeView + LearningStage — learning path
5. AgentsView, ProductsView, ExamView — category pages
6. SearchView + SearchBar — search
7. Composables — useSearch, useProgress

### Build & Deploy
1. `npm create vite@latest` scaffold
2. `python build.py` to generate data
3. `npm run build` to produce dist/
