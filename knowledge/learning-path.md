# AI 学习路线图

> 面向 AI 产品经理的系统学习路径，从基础认知到产品落地

## 第一阶段：基础认知

- [ ] 了解机器学习基本概念（训练/推理、过拟合、损失函数）
- [ ] 了解 Transformer 架构原理
- [ ] 理解 Attention 机制
- [ ] 掌握 Token、Embedding 等基本概念
- [ ] 了解数据基础（数据集、标注、数据质量）
- [ ] 了解模型评估指标（准确率、F1、困惑度等）
- [ ] 阅读：Attention Is All You Need

## 第二阶段：大语言模型

- [ ] 了解 GPT 系列演进（GPT-1/2/3/4）
- [ ] 了解开源模型：LLaMA、Mistral、Qwen、DeepSeek
- [ ] 理解预训练 → SFT → RLHF 训练流程
- [ ] 了解 Scaling Laws 与 Chinchilla 定律
- [ ] 理解推理优化（量化、蒸馏、推测解码）
- [ ] 阅读：InstructGPT、LLaMA、Scaling Laws 论文

## 第三阶段：对齐与安全

- [ ] 理解 RLHF 原理与实现
- [ ] 了解 DPO、Constitutional AI
- [ ] 了解红队测试与安全评估方法
- [ ] 关注 AI Safety 前沿动态

## 第四阶段：RAG 与应用架构

- [ ] 理解 RAG（检索增强生成）原理与架构
- [ ] 了解向量数据库与 Embedding 检索
- [ ] 学习 Agent 设计模式（ReAct、Plan-and-Execute）
- [ ] 了解主流框架（LangChain、AutoGen、CrewAI）
- [ ] 动手搭建一个 RAG 或 Agent 应用

## 第五阶段：多模态

- [ ] 了解视觉语言模型（GPT-4V、Gemini、Claude Vision）
- [ ] 理解 CLIP、多模态 Embedding
- [ ] 了解多模态应用场景（图文理解、文档解析、视频分析）

## 第六阶段：AI 产品

- [ ] 研究主流 AI 产品设计思路
- [ ] 学习 Prompt Engineering 与 Few-shot 设计
- [ ] 了解 AI 产品指标体系（准确率、延迟、成本、用户满意度）
- [ ] 学习 AI 产品的用户研究方法
- [ ] 思考 AI 产品的差异化与壁垒

## 横向主题：AI 治理与合规

- [ ] 了解 EU AI Act 等全球 AI 监管趋势
- [ ] 理解数据隐私与安全（GDPR、模型数据泄露风险）
- [ ] 了解 AI 伦理框架与负责任 AI 实践
- [ ] 关注 AI 版权与知识产权争议
