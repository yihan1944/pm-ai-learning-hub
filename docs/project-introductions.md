# 项目介绍

## 1. PM AI Learning Hub（AI 产品经理学习中心）

**在线地址：** https://ai.viewe.cn/

**项目简介：**
一个面向 AI 产品经理的个人学习知识库，将散落在各处的学习资源（论文笔记、学习路线、面试题、产品案例等）整合为一个结构化的静态网站。目标是帮助自己系统性地构建 AI 产品经理知识体系，同时也为同路人提供参考。

**核心功能：**
- **学习路线** — 7 阶段 + 2 个横向专题的学习路径，38 个可勾选的学习项，进度自动保存在浏览器本地
- **论文笔记** — 按类别分组（基础架构、大语言模型、对齐与安全、多模态），支持 Markdown 渲染、目录导航、PDF 下载
- **面试题库** — AI 产品经理岗位面试题，点击展开答题方向
- **AI 产品案例** — 产品展示与分析
- **Agent 资源** — Agent 框架、设计模式、项目实践（建设中）
- **全局搜索** — 跨全站内容的关键词搜索

**技术栈：**
- 前端：Vue 3（Composition API + `<script setup>`）+ TypeScript + Vite
- 内容管理：Markdown 文件 → Python 构建脚本（`build.py`）→ JSON → Vue 组件静态导入
- 样式：纯 CSS 自定义属性，暗色主题，无 UI 框架
- 路由：Vue Router（Hash 模式），全部懒加载
- 部署：GitHub Actions → GitHub Pages，自定义域名 `ai.viewe.cn`

**架构特点：**
- 纯静态站点，无后端、无数据库、无认证，所有内容在构建时打包
- 两阶段构建：`python build.py`（内容生成）→ `npm run build`（前端打包）
- 渐进式信息架构：首页概览 → 分类列表 → 内容详情，最多 2 次点击到达任意内容
- 全站移动端适配（320px+）

## 2. 汴州往事

**在线地址：** https://wuxia.viewe.cn/

**项目简介：**
一部以隋末汴州为背景的中文历史架空小说，目前为初稿阶段，共 34 章。故事围绕信息掮客顾衡展开——他自以为在操纵全局、收割利益，却不知早已是别人棋盘上的一颗棋子。

**内容特色：**
- 历史架空题材，设定在隋朝末年动荡时期
- 主题围绕权谋、信息操控、尔虞我诈
- 章节式连载，从酒楼起笔，逐步推进至虎牢关等大战场面
- 以「棋子」为隐喻，探讨个体在权力博弈中的命运

**技术实现：**
- 纯静态 HTML 站点，各章节为独立 `.html` 文件
- 无前端框架，无构建工具，轻量直接

## 4. 梦境笔记

**在线地址：** https://dream-diary-virid.vercel.app/

**项目简介：**
一个部署在 Vercel 上的梦境分析 Web 应用，用于记录梦境内容并接入 DeepSeek 进行智能解构与分析。用户可以将自己的梦境记录下来，通过 AI 从心理学、象征学等角度进行解读。

**核心功能：**
- 梦境记录与管理
- 接入 DeepSeek 大模型进行梦境解构与分析
- 单页应用（SPA）架构，流畅的交互体验

**技术实现：**
- SPA 架构，部署于 Vercel
- AI 后端：DeepSeek 模型

## 5. 梦境分析 CLI（dream-cli）

**GitHub 地址：** https://github.com/yihan1944/dream-cli

**项目简介：**
一款基于 AI 的命令行梦境分析工具，面向喜欢在终端中工作的用户。通过 OpenAI API 对用户输入的梦境内容进行智能解读，支持多种分析风格和双语输出。

**核心功能：**
- 支持直接文本输入或从文件读取梦境内容
- 三种分析风格：简要（brief）、详细（detailed）、象征性（symbolic）
- 支持中文和英文双语输出
- 支持第三方 OpenAI 兼容 API（可自定义 base URL）
- 灵活的配置管理（`dream init` / `dream config`）

**技术实现：**
- 语言：Python
- AI 后端：OpenAI API（支持 GPT-4 及自定义端点）
- 配置存储：`~/.dream-cli/config.json`
- 开源协议：MIT
- 安装方式：`git clone` → `pip install -e .`
