# 用AI做产品 - 面试题集

> 面向产品经理如何利用AI工具（ChatGPT、Cursor等）提升工作效率

## 一、AI工具应用实战

### 1. 你日常工作中使用哪些AI工具？请举例说明使用场景。

**考察点**: AI工具使用广度和深度
**答题方向**:
- 对话类：ChatGPT/Claude（需求分析、文档撰写、竞品调研）
- 编程类：Cursor（原型开发、代码理解、日志分析）
- 设计类：Midjourney/Figma AI（视觉素材、UI设计）
- 数据类：ChatGPT Data Analyst（数据分析、可视化）
- 要给出具体场景和提效数据

### 2. 请分享一个你使用Cursor或ChatGPT独立完成高保真原型的案例。

**考察点**: 实战能力
**答题方向**:
- 需求背景：什么产品、什么功能
- 工具选择：为什么选这个工具
- 实现过程：如何用AI生成前后端代码
- 效果对比：传统方式需要多久 vs AI辅助用了多久
- 踩坑经验：遇到了什么问题、如何解决

### 3. 使用AI工具后，你的PRD编写效率提升了多少？请给出具体场景。

**考察点**: 效率提升量化能力
**答题方向**:
- 传统PRD：需求调研2天 + 撰写1天 + 评审修改1天 = 4天
- AI辅助：用ChatGPT整理用户反馈、生成初稿、优化措辞，压缩到2天
- 关键点：AI生成初稿 + 人工审核修改，不是完全依赖AI

### 4. 你如何利用AI工具与开发团队协作？

**考察点**: 跨团队协作能力
**答题方向**:
- 用Cursor解释技术方案，理解开发实现难度
- 用ChatGPT将技术术语翻译成产品语言
- 用AI分析日志，快速定位问题
- 用AI生成测试用例，提升验收效率

## 二、Prompt Engineering

### 5. 什么是提示词工程？你在工作中如何应用？

**考察点**: 核心技能
**答题方向**:
- 定义：通过设计输入提示来引导AI输出期望结果的技术
- 应用场景：需求文档生成、用户画像构建、竞品分析
- 关键技巧：角色设定、上下文提供、输出格式约束、分步引导

### 6. 请展示一个你设计的高质量Prompt。

**考察点**: 实操能力
**答题方向**:
- 结构：角色 + 任务 + 上下文 + 输出格式 + 约束条件
- 示例（PRD生成）：
  ```
  你是一位资深产品经理。基于以下用户反馈，生成一份PRD初稿：
  - 功能名称：[名称]
  - 用户反馈：[内容]
  - 输出格式：包含需求背景、用户故事、功能描述、验收标准
  - 约束：语言简洁，避免技术术语
  ```

### 7. AI生成的内容你如何验证和修正？

**考察点**: AI输出的批判性思维
**答题方向**:
- 事实核查：关键数据和结论需要人工验证
- 逻辑检查：是否有前后矛盾
- 风格对齐：是否符合公司文档规范
- 最佳实践：AI生成70% + 人工修正30%

## 三、AI提效方法论

### 8. 如何用AI工具打通产品工作流？

**考察点**: 系统化思维
**答题方向**:
- 需求阶段：ChatGPT分析用户反馈 → 生成用户画像
- 设计阶段：AI生成流程图 → Cursor快速原型
- 开发阶段：AI辅助写测试用例 → 分析日志
- 运营阶段：AI分析数据 → 生成周报
- 关键：不要孤立使用工具，形成工作流闭环

### 9. 产品经理使用AI工具的边界在哪里？哪些事情不应该交给AI？

**考察点**: 理性判断
**答题方向**:
- 不应交给AI：最终产品决策、用户访谈、敏感数据处理、对外沟通
- AI辅助：数据分析、文档撰写、方案头脑风暴
- 边界判断：涉及人际关系、战略判断、创意突破的工作需要人主导

### 10. 你如何保持对AI工具的持续学习？

**考察点**: 学习能力
**答题方向**:
- 信息源：关注行业KOL、订阅技术博客、参加社区讨论
- 实践：每周尝试一个新工具或新用法
- 输出：写使用心得、做内部分享
- 思考：不只是会用，更要思考如何与业务结合

## 四、面试加分项

### 11. 你有没有用AI工具做过个人项目？请展示。

**考察点**: 主动性和动手能力
**答题方向**:
- 哪怕是简单的Todo App、个人网站、数据看板
- 关键是展示：从想法到实现的完整过程
- 加分点：用了哪些AI工具、遇到了什么问题、如何解决

### 12. 你认为AI会取代产品经理吗？

**考察点**: 行业洞察
**答题方向**:
- 不会取代，但会淘汰不会用AI的产品经理
- AI擅长：信息处理、文档生成、数据分析
- 人的价值：用户洞察、商业判断、团队协作、战略规划
- 趋势：产品经理的角色会从"功能设计"转向"AI驱动的价值创造"
